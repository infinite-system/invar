## In plain words

Let the graph describe its own shapes: `describe tasks.byNumber.553`
answers which fields exist and what types they take, generated from
the TypeScript compiler — so agents learn argument shapes from the
graph instead of reading source.

## Scope seed

Build-time pass over the TS compiler API emitting a semantic
projection (method names, parameter names + types, return types,
JSDoc, source locations) per exported class; graph verb `describe
<path>`; generated-never-authored (one authority, many projections);
regenerated by the gate so it cannot drift (regenerate-and-diff is the
mechanical check). Load-bearing once M3/#559 give the graph verbs
whose arguments need describing. Generalizes to the app's classes and
any TS repo; LSP is the later language-neutral adapter.
