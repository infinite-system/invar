# Brief 522-3 — plain Escape/Enter/Backspace now emit the modified byte form

## In plain words

Your new chord branch fires for Enter, Escape, and Backspace whether or
not a modifier is pressed. So a PLAIN Escape now sends the
modifyOtherKeys sequence with modifier parameter 1 instead of the bare
escape byte. Every smoke that closes a sheet with Escape breaks. Gate
the branch on an actual modifier.

## The diagnosis (conductor, verified)

- Merge base: `bun scripts/harness/smoke-shortcut-help-harness.ts` is
  GREEN. Your branch is RED at "sheet shows the Quit action" on a QUIET
  machine (gate-522-r2, single gate) — so this is your diff, not load.
- Root cause: HarnessInput.ts `$key`, the new
  `modifyOtherKeysCodepoint` branch has no modifier guard. For plain
  `Escape`: baseKey='Escape', hasShift/Alt/Control all false,
  chordModifierParameter = 1+0+0+0 = 1, returns `\x1b[27;1;27~`.
  Pre-branch, plain Escape returned the bare `\x1b`. The app's Escape
  path in the shortcut sheet expects the bare byte.
- Your round-2 byte census reported "added forms only, altered none" —
  it tested modified chords but not the PLAIN Enter/Escape/Backspace
  that fall through the same unguarded lookup. That is the census hole.

## The fix

Fire the modifyOtherKeys branch ONLY when a modifier is present:
`if (modifyOtherKeysCodepoint !== undefined && (hasShift || hasAlt ||
hasControl))`. Plain Enter/Escape/Backspace must keep their exact
pre-branch byte forms. Extend the census to prove it: for EACH of
Enter/Escape/Backspace, assert the UNMODIFIED byte form is
byte-identical to the merge base, and the modified forms are the new
sequence.

## End state (mechanically checkable)

`bun scripts/harness/smoke-shortcut-help-harness.ts` green in your
worktree; a full `bun test` green; the extended census (plain forms
unchanged vs merge base) in the report.

## The bar

The founding harness invariant: a key's bytes must be what a real
terminal emits — and plain Escape emits `\x1b`, not a modifyOtherKeys
frame. No timeout widening; this is a correctness fix.
